# Zomato Restaurant Insights Dashboard

Interactive Power BI dashboard analyzing 9,551 restaurants across 141 cities and 15 countries.

## Key Insights
- New Delhi leads with 5,473 restaurants
- North Indian is the most common cuisine (3,960 listings)
- 25.7% of restaurants offer online delivery
- 12.1% of restaurants offer table booking

## Tools Used
Power BI, DAX

Built as part of Data Science & Generative AI training at AlmaBetter.
